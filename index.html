1. 网页基础

输入网址后，浏览器通常先通过 DNS 查询域名对应的 IP 地址，然后通过 HTTP 或 HTTPS 向服务器发出请求。服务器返回响应，浏览器读取响应并显示网页。

2. HTML

HTML 用来组织网页内容。例如，这个页面用 <nav> 放导航链接，用 <main> 放主要内容。

3. CSS

CSS 控制网页的样式。后面可以用 Grid 排列学习卡片，用 Flexbox 排列导航链接。

4. JavaScript

JavaScript 可以让网页响应操作。后面可以做一道小测验，点击按钮后在页面上显示结果。

5. 项目开发

先写内容，再加样式和交互。每完成一部分，就用浏览器打开页面检查。

6. 部署与托管

Git 用来记录项目的修改。完成后可以上传到 GitHub，再用 GitHub Pages 发布网页。
